# Wanderly India — Full Stack Travel Booking Website

A polished Indian travel booking website built with React + Vite and Flask. Prices are displayed in Indian Rupees (₹).

## Features
- Premium responsive travel UI
- Indian and international destinations
- Destination search
- Curated tour packages
- Hotel-style stays section
- Offers
- Booking modal with traveller details
- Flask REST API
- PostgreSQL schema
- Login/register API endpoints

## Run Backend
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
pip install -r requirements.txt
python run.py

Backend: http://localhost:5000

## Run Frontend
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173

The demo UI works immediately with the included content. PostgreSQL tables are defined in database/schema.sql.
